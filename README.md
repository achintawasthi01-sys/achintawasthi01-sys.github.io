# Achint — Portfolio

Static website (HTML + CSS + JS). Build step nahi, seedha deploy hota hai.

Files: `index.html` (content) · `style.css` (design + loader) · `main.js` (animations, edit mode) · `achint.jpg` (photo)

Deploy: GitHub Pages → Settings → Pages → Branch `main` / root.
Edit mode: site link ke aage `?edit` lagao, Edit → Save changes → download hui `index.html` se purani replace karo.
Loader speed: `main.js` mein `MIN=2400` (ms).
